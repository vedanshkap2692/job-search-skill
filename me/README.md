# me/

Your own material. The agent writes these files from your conversations (starting from the blanks in `templates/`); you can read or edit any of them.

- `profile.md`: who you are, what you're looking for, filters, standard form answers, and how far setup has got.
- `master_resume.md`: everything you can claim: projects, numbers and where they came from, ready-made bullets, a "not claimed" list, and exact wording for qualified claims. The only source resumes, forms and messages draw from.
- `style.md`: your feedback, written down as rules so the agent doesn't repeat a mistake.
- `permissions.md`: what the agent may do without asking you, with dates.
- `templates/`: the blank starting points for the four files above (these are the only files here that ship with the repo).
- `resumes/`: base resumes in `base/`, and one folder per tailored application holding the resume and a `notes.md` (what the JD asked for and how the resume covers it, the review, form answers). The JDs themselves live in `data/jds/`.
- `sources/`: anything you hand over for the resume: old resumes, a LinkedIn PDF, recording transcripts, reviews.
- `prep/`: interview prep and study plans, one folder per company.

Everything here except this file and `templates/` is gitignored, so it stays on your machine.
